# Privacy Policy

**Last updated:** August 4, 2026

## Overview

This extension is designed to help users perform Microsoft Rewards searches more efficiently by automating Bing searches with dynamically generated search terms.

Your privacy is important. This extension has been designed to operate without collecting, storing, sharing, or selling any personal information.

---

## Information We Collect

**We do not collect any personal information.**

The extension does **not**:

- Collect personal data.
- Collect browsing history.
- Track user activity.
- Read or store passwords.
- Access emails, files, or personal documents.
- Sell or share any user information with third parties.

---

## How the Extension Works

The extension automates Bing searches requested by the user using dynamically generated search terms.

To provide this functionality, it:

- Opens Bing search tabs.
- Types and submits search queries automatically.
- Scrolls the search results page.
- Closes the tab after the search is completed.

The extension operates only for its intended purpose and does not monitor or record user activity outside of this functionality.

---

## Permissions

The extension requests only the permissions necessary for its intended functionality.

These permissions are used to:

- Create, update, and close browser tabs during automated searches.
- Execute scripts on Bing pages to simulate user interaction.
- Schedule automated search tasks.
- Access Bing and public word-generation APIs required to perform searches.

These permissions are **not** used to collect, monitor, or transmit personal information.

---

## Third-Party Services

The extension communicates only with the following public services as part of its core functionality:

- Bing
- Random Word API
- Datamuse API
- PayPal (only if the user voluntarily chooses to make a donation)

No personally identifiable information is transmitted by the extension to these services.

---

## Data Storage

The extension does not maintain a remote database.

It does not send user information to any server owned or operated by the developer.

Any extension settings are stored locally using the browser's built-in storage mechanisms and remain on the user's device.

---

## Data Sharing

The extension does **not**:

- Sell user data.
- Share user data with third parties.
- Use data for advertising.
- Use data for analytics or tracking.

---

## Children's Privacy

This extension is not directed toward children under the age of 13 and does not knowingly collect any personal information from children.
